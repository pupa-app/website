How “Open in Pupa” works

A .pupa bundle is inert, portable data — no code runs on import. However it reaches Pupa, the app shows a confirm preview so you can review the app’s agent prompts before installing.

  • iPhone & iPad: tap → Pupa opens and fetches the app, then shows the confirm preview. Nothing is saved to your device first. Don’t have Pupa yet? Use the download button beside it to save the .pupa file for later.
  • macOS: the file downloads — open it to launch Pupa.
